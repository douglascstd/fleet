This module is an add-on for the Fleet application in Odoo. It extends
``fleet_traccar_integration`` to synchronize the Traccar geofences and
events into Odoo:

- **Geofences** (``traccar.geofence``): the geofences defined in
  Traccar, with their name, description, area, calendar and attributes.
  They can be synchronized on demand or from a server action.
- **Events** (``traccar.event``): the events reported by Traccar (alarm,
  geofence enter/exit, device status, etc.), with their type, date,
  device and vehicle, related geofence and telemetry point, message and
  raw data.
- Events are deduplicated by Traccar ID and relinked to the
  corresponding device/geofence/telemetry records when they are
  available later.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Configuration
=============

This module requires ``fleet_traccar_integration`` to be configured with
a valid Traccar server, as it reuses the same per-company connection
settings.

Usage
=====

Open *Fleet > Configuration > Traccar*, where two new menus are
available:

- *Geofences* and *Sync Geofences*.
- *Events* and *Sync Events*.

The *Sync Geofences* and *Sync Events* buttons can also be used from the
geofences and events views, or as server actions on the corresponding
models.
